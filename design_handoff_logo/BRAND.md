# SternCut brand handoff

- Ink: `#101010`
- Canvas/light: `#F8F8F6`
- Gold: approximate `#E7B85D` (logo source is raster, so this is a practical UI token rather than an exact vector color)

## Mark
Use the S + sparkle mark only for compact UI surfaces. Do not add the STERNCUT wordmark to the launcher icon or notification icon.

## Export notes
- PNG, square, no text on icons.
- Android adaptive foreground is transparent and kept inside a conservative safe area.
- Notification icon is white-only on transparency.
